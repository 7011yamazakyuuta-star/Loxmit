# Public Introduction Kit

This is prepared copy, not evidence that an announcement has been posted.
Before posting, replace any version reference with the published release and
follow each community's self-promotion and security-tool rules. Do not mass-post.

## English Introduction

Loxmit is an open-source, local-first desktop app for recovering access to your
own password-protected PDF, Office, and ZIP files. It provides an English/Japanese
interface over Hashcat, clue-based search planning, optional GPU checks, and
verified unlocked-file exports. Windows, macOS, and Linux packages are available
through GitHub Releases. Documents and passwords are not sent to a cloud service.

It is alpha software, not an official Hashcat product. Recovery is not guaranteed,
and it does not claim to be universally faster than Hashcat. Current packages
are unsigned/unnotarized, stored data is not encrypted by the app, and document
workers are not full security sandboxes. Reproducible bug reports and platform
feedback with synthetic files are especially useful.

Project: https://github.com/7011yamazakyuuta-star/Loxmit

## 日本語紹介

Loxmitは、自分のPDF・Office・ZIPファイルを対象に、忘れたパスワードの探索と解除済みファイルの保存を行うローカルアプリです。日本語・英語の画面、手掛かりからの探索、任意のGPU診断に対応し、Windows・macOS・Linux向けにGitHub Releasesで配布しています。文書やパスワードはクラウドへ送信しません。

現在はアルファ版で、Hashcat公式製品ではありません。復元成功やHashcatを常に上回る速度は保証しません。正式な署名・公証、アプリ独自の保存暗号化、完全なOS隔離は未対応です。個人文書ではなく人工データによる不具合報告・環境別の検証報告を歓迎します。

## Suggested Order

1. Publish a verified prerelease with clear platform limits and both language guides.
2. Invite a small number of testers; collect OS/GPU/version and reproducible results.
3. Share a concise introduction in relevant open-source or desktop-tool communities,

4. Add measured compatibility results before broadening claims or promotion.

dual-language documentation, and safe issue templates are already useful without
